# Diagrams
{: .no_toc }

Dr. Jekyll supports various types of diagrams that can be easily created using simple syntax. These diagrams can help you visualize complex concepts, workflows, and relationships in a clear and concise manner.

{% include toc.md %}

---

## [Mermaid](mermaid.md)

[Mermaid](https://mermaid.ai/open-source/intro/) lets you create diagrams and visualizations using text and code. It supports a wide range of diagram types, including flowcharts, sequence diagrams, class diagrams, state diagrams, and more. Mermaid is a powerful tool for creating dynamic and interactive diagrams that can be easily integrated into your documentation.
